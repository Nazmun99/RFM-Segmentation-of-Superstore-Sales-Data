## Superstore Sales
# Overview
This project is an analytical project for Superstore Sales Data whereas the project involves the segmentation of customers based on Recency, Frequency and Monetary(RFM) metrics. The analysis aims to understand customer behavior and analyze them accordingly to find out high_value customers.
# Files:
_'_SuperstoreSales_Data.csv_': _The raw sales data file.
_'Create_database.sql'_: This SQL scripts will create the database and tables.
_-'data_cleaning_eda.sql':_Data Check
- rfm segmentation.sql: Find Recency, Frequency and Monetary metrics for customers
